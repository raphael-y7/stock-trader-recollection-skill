# 股票大作手回忆录（丁圣元注疏版） — 全书能力入口

## 触发与不触发

**适用**：与本书能力域相关的咨询与任务（见下方路由表的意图列）。
**不适用**：
- 日内短线打板与高频交易信号（原书时间尺度为波段至主要趋势层级）
- 个股基本面估值与财务分析（原书不提供估值方法）
- 具体买卖点位推荐与代客操作建议
- 期货外汇等其他市场的直接操作指引（原则可迁移但制度不同）

## 核心原则（常驻速览，概览类问题读到这里即可回答）

1. 大势优先：大钱来自主要趋势，先判方向与时机再谈操作
2. 关键点入场：横盘记录上下极限，确定无疑的突破才动手，跌回关键点即离场
3. 试探建仓：首笔 1/5 试探，首笔有账面利润才加码，绝不摊平
4. 盘面优先：价格行为先于消息与解释，"空头打压"100 例 99 例是合理下跌
5. 防范自己：希望与恐惧倒过来用，仓位压到睡得着，亏损写成戒律
6. 知行鸿沟与制度风险：规则本身不保证盈利——传主五次破产（1940 年终告破产自杀）、咖啡交易被政府干预清零，执行纪律与制度环境是双重前提
