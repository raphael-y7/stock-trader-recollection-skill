# 决策规则速查 — 股票大作手回忆录（丁圣元注疏版）

| 能力 | 一句话规则 |
|---|---|
| 最小阻力路线趋势判读 | 先用高低点结构把市场判为上升/下降/横向三态，只顺势出方向结论；横向市不出方向只等突破；方向与时机两项评估齐全才允许动手。 |
| 关键点体系 | 横盘期记录区间上下极限绝不沾手，关键点被确定无疑突破才顺向动手，跌回关键点即判整轮行情为假象立即离场。 |
| 试探—验证—加码建仓程序 | 先以额度 1/5 试探，首笔有账面利润才加第二笔且只沿盈利方向步步加码，首笔亏损即终止程序、绝无补仓分支。 |
| 头寸管理：持有、跟进与退出 | 大势未坏就拿住头寸，只在盈利侧跟进止损，识别做错即零延迟离场，绝不摊平、绝不卖盈保亏。 |
| 交易心理与状态自检 | 下单前查希望恐惧是否倒置、动机是否为账单、仓位是否压得睡不着；只站市场正确的一边，每笔亏损必须转化为一条戒律。 |
| 贴士与权威信息防御 | 先看盘面再看消息——出场依赖链断裂即拒信、匿名默认不可信、下跌先验为合理下跌（100 例 99 例）、行为证据压倒言语。 |
| 个股与板块行为甄别 | 板块同涨同跌是常态，掉队与滞涨先于消息发出警告：行为不对路的股票不碰，领头羊集体回落不收复即牛市尾声预警。 |
| 流动性与执行 | 下单前算相对成交量占比与滑点预算，大额先测市场胃口——"能在卖出的时候卖出，而不是想卖出的时候卖出"。 |
| 判断校准预测日志 | 把判断事前写成可核对记录（方向/幅度/窗口/依据），到期逐条判对错——真金小额或明确标记演练验证观察是否精准。 |
| 利弗莫尔成文规则总表 | 按场景检索 15 条成文规则→照录条文与出处→标注边界并转介深度卡——清单用于查违规，不用于保证盈利。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
